# Provisional kill / pivot thresholds (awaiting owner approval)

Set by the orchestrator as starting numbers; the Researcher should sanity-check them against real data and propose changes. A brand-new domain typically needs months to earn impressions.

| Threshold | Provisional value | Measured by |
|---|---|---|
| Min combined monthly searches, target cluster (Columbus metro) | 3,000 | Keyword Planner / proxy |
| Min distinct licensed management companies found | 60 | Source registry |
| Min pages publishable with unique structured data | 150 | Build report |
| Month-3 organic impressions per month | 1,000 | Search Console |
| Month-6 organic impressions per month | 10,000 | Search Console |
| Month-6 monthly organic visits | 300 | Google Analytics 4 |
| Month-12 monthly organic visits | 2,000 | Google Analytics 4 |

Decision rule: below the first three thresholds -> widen to landlord topics or switch to home services; below month-3/6 thresholds -> revisit page quality and taxonomy before building more.
